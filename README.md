- **Tech**: Rust, WebAssembly (wasm-bindgen), Vite, TypeScript, Canvas
- **Play it now!** [alvarodiez20.github.io/tetris/](https://alvarodiez20.github.io/tetris/) (Desktop keyboard + mobile touch, with Smart & Random AI bots!)
